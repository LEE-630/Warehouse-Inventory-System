# Warehouse-Inventory-System

A console-based **Warehouse Inventory Management System** written in C++, built as a group project for **TDS4223** (Group 7). It supports three user roles — SuperAdmin, Admin and Customer — and stores all data in plain-text flat files under `data/`.

## Features

**Login & accounts**
- Role-based login (Admin / SuperAdmin / Customer)
- Customer self-registration with username and password validation
- All users held in a single linked list loaded from `data/Admin.txt` and `data/Customer.txt`

**Admin**
- View inventory (with optional sort)
- Sort inventory by quantity or price (merge sort)
- Search product by ID (binary search)
- Add product (auto-generated product ID)
- Update / edit a full product record
- Generate low-stock report (threshold ≤ 10 units) → `data/LowStockReport.txt`
- View a customer's orders

**SuperAdmin** — everything Admin can do, plus
- Delete product
- Register new Admin accounts
- View stock summary (total units, total value, low-stock count)
- Customer view mode

**Customer**
- Browse available inventory
- Place orders (stock is deducted automatically)
- View, search (binary search), edit, delete and sort own orders
- Generate order summary → `data/OrderSummary.txt`

## Data structures & concepts used

- Singly linked lists (`Product`, `Order`, `User`)
- Merge sort and binary search
- Inheritance and polymorphism (`User` → `Admin`, `SuperAdmin`, `Customer`, with virtual `displayMenu()`)
- Friend functions (`displayInventoryForCustomer`, `generateStockSummary`, `adminViewCustomerOrders`, `printUserProfile`)
- Exception handling for menu input
- File I/O with `|`-delimited records

## Project structure

```
Warehouse-Inventory-System/
├── main.cpp            # Entry point: login menu, registration, user list
├── admin.cpp / admin.h # Admin & SuperAdmin classes, file I/O for inventory/admins
├── customer.cpp / .h   # Customer class and order handling
├── Lead_backend.cpp    # ProductLinkedList implementation (sort / search / display)
├── backend.h           # ProductLinkedList declaration
├── structures.h        # Product, Order structs and User base class
├── Project_GR7.cpp     # Integrated single-file version of the whole project
└── data/
    ├── Admin.txt         # username|password|role
    ├── Customer.txt      # username|password|role
    ├── Inventory.txt     # id|name|category|qty|zone|supplier|price
    ├── Orders.txt        # customer|orderId|productId|name|category|qty|date
    ├── OrderSummary.txt  # generated report
    └── LowStockReport.txt# generated report
```

## Build & run

Requires a C++ compiler such as g++ (MinGW on Windows). Run the program from the project root so it can find the `data/` folder.

**Multi-file version** (`main.cpp` pulls in the other `.cpp` files via `#include`, so compile only `main.cpp`):

```bash
g++ main.cpp -o main
./main          # Windows: main.exe
```

**Single-file version:**

```bash
g++ Project_GR7.cpp -o Project_GR7
./Project_GR7   # Windows: Project_GR7.exe
```

> Some file paths in the customer module use Windows-style separators (`data\\Orders.txt`), so the program is intended to be run on Windows.
